# Planificador de Tareas Web

El proyecto consiste en desarrollar una aplicación web para la gestión y planificación de tareas, diseñada para permitir a los usuarios registrar, organizar y consultar sus actividades de manera sencilla e intuitiva.

La aplicación permite crear tareas ingresando información como nombre, descripción, fecha de entrega, prioridad y estado. Además, cuenta con funcionalidades de búsqueda, filtros por estado, calendario y administración de tareas, incluyendo opciones para editar, completar y eliminar tareas. La interfaz utiliza HTML, CSS, JavaScript y Bootstrap, junto con SweetAlert2 para mostrar mensajes de confirmación y validación.

En general, el proyecto busca ofrecer una herramienta sencilla para organizar actividades, controlar fechas de entrega y mejorar la gestión de tareas desde una interfaz web.
